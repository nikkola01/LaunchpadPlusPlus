# Attribution

Launchpad++ is a modified continuation of the **Launchpad / LaunchpadPlus** macOS project by **Kristóf Papp**:

- Upstream repository: <https://github.com/kristof12345/Launchpad>
- Upstream author: Kristóf Papp

It is not presented as an unrelated clean-room implementation. Launchpad++ changes the user-facing name and extends or revises the original app with, among other changes:

- an always-free official release experience without activation or premium feature gates;
- live settings preview with explicit Save and Cancel behavior;
- expanded grid capacity and adaptive icon sizing;
- separate app-area top and bottom margins;
- label size and color controls;
- optional categories, category auto-fill, and multi-icon category previews;
- finer background opacity controls;
- updated shipping defaults and support link.
