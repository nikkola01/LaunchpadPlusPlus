# Launchpad++ Security Policy

## Supported versions

Security fixes are provided for the latest published Launchpad++ release. Older builds may not receive fixes, so please update to the latest release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature when it is enabled for this repository. If it is unavailable, contact the maintainer privately through the contact method listed in the repository profile before opening a public issue.

Include:

- the Launchpad++ version and release filename;
- macOS version and Mac architecture;
- a concise description of the impact;
- reproducible steps or a minimal proof of concept;
- whether the issue exposes local files, changes settings, or launches an unintended application.

Do not attach private layout/category exports, personal filesystem paths, crash logs containing personal data, or a working exploit to a public issue.

## What to expect

The maintainer should acknowledge a credible private report, investigate it, and coordinate a fix and disclosure timeline. This volunteer project cannot promise a specific response time or bug bounty.

## Safe downloads

Only install Launchpad++ from this repository's [Releases](../../releases) page.
